配置参考

顶层参数：width_mm/height_mm 成品尺寸（毫米，>0）；bleed_mm 出血（默认 3）；dpi 分辨率（默认 150）；bitdepth 8 或 16；color_profile 如 srgb。

background：背景层。enabled 是否生成；fill_color RGB 三元组，如 [255,255,255]。

zones（图层，核心）：至少 1 个。每个区独有尺寸/位置，name 须 ASCII 且尺码内唯一（写入 PSD 图层名）。

  • 图片区 type:"image"：承载上传图。fit_mode：stretch（拉伸铺满）/ contain（等比留白）/ cover（裁切铺满）。
  • 纯色区 type:"color"：color 手动 RGB 或 auto_color 自动提取主色（source 指向同尺码图片区 name，method 为 dominant/average），二选一。
  • 四角裁剪 corner_crop：style = square/rounded/chamfer。

marks（标记层）：裁剪线 / 拉链标记 / 文字标记 / 边框标记，各自开关。

output：formats 非空数组（psd/tif/png）；save_name 支持占位符。

图形编辑器与 JSON 双向同步；保存时后端校验兜底。
