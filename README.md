# 印前文件服务器（Prepress File Server）

> 状态：规划中 · 仅文档框架，暂不实现代码
> 最后更新：2026-08-26

## 项目定位

一个面向家纺/床上用品印前环节的 **Web 服务**：用户上传一张设计图片，选择产品类型与尺码，系统按预设配置自动生成对应的**印前图片文件**（PSD / TIF / PNG）。

典型场景：床单、床笠、被罩 A 面、被罩 B 面、枕套等床上用品，不同类型有不同的尺码规格，每种规格对应特定的印前排版参数（尺寸、出血、分辨率、分层等）。

## 技术架构

- **形态**：Web 应用，**前后端不分离**（服务端渲染页面 + 接口同进程）
- **交互**：浏览器打开页面 → 上传图片 → 选择类型 → 选择尺码 → 触发处理 → 下载结果
- **配置驱动**：产品类型与尺码通过**配置文件**定义，无需改代码即可增删规格

```
┌─────────────────────────────────────────────────┐
│                   浏览器页面                      │
│   上传图片 · 选类型 · 选尺码 · 查看进度 · 下载     │
└──────────────────────┬──────────────────────────┘
                       │ HTTP（同进程）
┌──────────────────────▼──────────────────────────┐
│                   Web 服务端                      │
│  ┌──────────┐ ┌──────────┐ ┌──────────────────┐ │
│  │ 页面渲染  │ │ 文件接收  │ │  任务处理引擎     │ │
│  │ (模板)   │ │ (上传)   │ │ 按配置生成印前图  │ │
│  └──────────┘ └──────────┘ └────────┬─────────┘ │
│         ▲                        ▲   ▼          │
│         │ 读取                   │  读取        │
│  ┌──────┴───────────────────────┴────────────┐  │
│  │          预设配置文件（树形）              │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

## 预设配置（树形结构）

配置通过**配置文件**定义，是两级树：

```
类型（第一级）
├── 床单
│   ├── 150x200cm
│   ├── 180x200cm
│   └── 200x230cm
├── 床笠
│   ├── 150x200cm
│   └── 180x200cm
├── 被罩A面
│   ├── 200x230cm
│   └── 220x240cm
├── 被罩B面
│   ├── 200x230cm
│   └── 220x240cm
└── 枕套
    ├── 48x74cm
    └── 50x70cm
```

- **第一级 — 类型**：产品大类，如床单、床笠、被罩A面、被罩B面、枕套等
- **第二级 — 尺码**：该类型下可选的具体规格，如 `150x200cm`

每个尺码节点下挂该规格的**印前参数**（尺寸、出血、DPI、分层规则、输出格式等），具体参数项在后续 `04-预检与生成参数` 文档中细化。

配置文件格式与示例将在 `02-配置文件规范` 中定义。

## 操作流程

```
1. 打开页面
   └─ 浏览器访问服务，进入主操作页

2. 上传图片
   └─ 选择一张设计图上传到服务器（支持常见位图格式）

3. 选择类型
   └─ 从配置树第一级选择产品类型（床单/床笠/被罩A面…）

4. 选择尺码
   └─ 类型选定后，第二级出现该类型下的可选尺码，选中其一

5. 生成印前图片
   └─ 服务端按选中类型+尺码对应的配置参数，处理上传图，生成印前文件
      输出格式：PSD / TIF / PNG（可多格式同时输出）

6. 下载结果
   └─ 处理完成，页面提供下载链接，用户取回生成文件
```

页面流程示意：

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌──────────────┐
│  ① 上传图片  │ → │  ② 选择类型  │ → │  ③ 选择尺码  │ → │  ④ 生成处理  │ → │  ⑤ 下载结果   │
│   [拖拽/选择] │   │ [床单/枕套…] │   │ [150x200…]  │   │  [进度/状态] │   │ [PSD/TIF/PNG]│
└─────────────┘   └─────────────┘   └─────────────┘   └─────────────┘   └──────────────┘
```

## 输出能力

按场景区分（spike 验证后定稿）：

| 场景 | 输出 | 分层 | 格式 |
|------|------|------|------|
| **印前生成**（单产品，尺寸小） | 分层文件 | ✅ 分层 | **PSD** |
| **排版输出**（超大版面，如 260×900cm） | 带透明 alpha 的平面 | ❌ 不分层 | **普通 TIF** |

- 印前生成：图案层+标记层分层存 PSD（后道微调）
- 排版输出：超大版面不分层，保留透明 alpha 通道，输出普通 TIF（通用，Photoshop/RIP 均可打开）
- 边界：8bit 适用；16bit 大尺寸超 4GB 须降级 bigtiff

> 技术约束：Python 生态无法写大尺寸分层文件（PSD 尺寸上限 30000px，PSB 分层无库支持），故大版面按平面 TIF 交付，符合印刷 RIP 收平面位图的行业惯例。详见 `docs/03-整体架构.md` 3.3 节。
