# 02 - 配置文件规范

> 状态：印前配置可在线读写（目录扫描式），排版只读，存储配置部分可改（任务并发上限） · 最后更新：2026-08-28

## 1. 设计原则

- **配置驱动**：产品类型、尺码、印前参数、排版参数全部由配置文件定义，不改代码
- **两套独立配置**：印前配置树（生成用）与排版配置（拼版用）相互独立，各自一个文件
- **格式**：JSON，可读、生态熟悉、嵌套结构友好
- **ASCII 命名**：图层名等会写入 PSD 的字段限 ASCII（psd-tools 限制，见 `03-整体架构` 3.3）

## 2. 配置文件总览

| 模块 | 文件 | 用途 | 读取方 | 加载时机 |
|------|------|------|--------|----------|
| 印前 | `configs/prepress/prepress.json` | 印前配置树：类型→尺码→生成参数 | config/prepress.py | 启动时加载，支持热更新（待定） |
| 排版 | `configs/impose/impose.json` | 排版配置：拼版幅面/咬口/标记等 | config/impose.py | 启动时加载 |
| 存储 | `configs/storage/storage.json` | 存储路径、缩略图规格、队列并发 | config/storage.py | 启动时加载 |

配置按模块分文件夹存放，每个模块独立目录，便于管理与扩展：

```
configs/
├── prepress/
│   └── prepress.json      # 印前配置树
├── impose/
│   └── impose.json        # 排版配置
└── storage/
    └── storage.json       # 存储与缩略图规格
```

> 后续新增模块配置时，在 `configs/` 下新建对应文件夹，如 `configs/web/`、`configs/logging/`。

## 3. 印前配置树（prepress.json）

### 3.1 结构

两级树 + 参数挂载：

```
类型（第一级）
└── 尺码（第二级）
    └── 印前参数（尺寸/出血/DPI/分层/输出）
```

### 3.2 字段定义

| 层级 | 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| 根 | `version` | int | 是 | 配置版本号，用于校验 |
| 根 | `types` | list | 是 | 类型列表 |
| 类型 | `id` | string | 是 | 类型唯一标识，ASCII，如 `bedsheet` |
| 类型 | `name` | string | 是 | 显示名（中文可），如 `床单` |
| 类型 | `sizes` | list | 是 | 该类型下的尺码列表 |
| 尺码 | `id` | string | 是 | 尺码唯一标识，ASCII，如 `150x200` |
| 尺码 | `name` | string | 是 | 显示名，如 `150x200cm` |
| 尺码 | `params` | object | 是 | 印前参数（见 3.3） |

### 3.3 印前参数（params）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `width_mm` | float | 是 | — | 成品宽（毫米） |
| `height_mm` | float | 是 | — | 成品高（毫米） |
| `bleed_mm` | float | 否 | 3 | 出血量（毫米），四周一致 |
| `dpi` | int | 否 | 150 | 输出分辨率 |
| `bitdepth` | int | 否 | 8 | 位深，8 或 16（16 时大图需 bigtiff） |
| `color_profile` | string | 否 | srgb | ICC profile 标识，如 `srgb` / `cmyk_coated` |
| `background` | object | 否 | — | 背景层（见 3.4） |
| `solid_layer` | object | 否 | — | 独立纯色层（见 3.4a） |
| `zones` | list | 是 | — | 区域列表（图片区/纯色区，见 3.5，至少 1 个） |
| `marks` | object | 否 | — | 标记层（见 3.6） |
| `output` | object | 是 | — | 输出设置（见 3.7） |

### 3.4 背景层（background）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `enabled` | bool | 否 | true | 是否生成背景层 |
| `fill_color` | list | 否 | [255,255,255] | 填充色 RGB |

### 3.4a 独立纯色层（solid_layer）

跨整画布的纯色层，位于 background 之上、zones 之下，作整画布基色层（如自动提取的产品主色底）。与 background 并存且独立。可选，未配置则不生成。

PSD 层序：background → **solid_layer** → zones → marks。

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `enabled` | bool | 否 | false | 是否生成纯色层 |
| `name` | string | 否 | SolidColor | 图层名，限 ASCII（写入 PSD） |
| `color` | list | 否 | — | 手动填充色 RGB，与 `auto_color` 二选一 |
| `auto_color` | object | 否 | — | 自动提取主色（见 3.5d），与 `color` 二选一；`source` 须指向同尺码图片区 name |


### 3.5 区域（zones，核心）

一个尺码可配置**多个区域**，每个区独立尺寸/位置/裁剪/微调。区有两种类型：
- **图片区**（`type: image`）：承载上传图
- **纯色区**（`type: color`）：填充纯色，可手动指定或从某图片区自动提取主色

**层名必须 ASCII**。所有区域共享以下基础字段：

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `name` | string | 是 | — | 区名（PSD 图层名），ASCII，如 `FaceA` / `Border` |
| `type` | string | 是 | `image` | `image`(图片区) / `color`(纯色区) |
| `x_mm` | float | 是 | — | 左上角 X（毫米，相对画布左上角） |
| `y_mm` | float | 是 | — | 左上角 Y（毫米） |
| `width_mm` | float | 是 | — | 区宽（毫米） |
| `height_mm` | float | 是 | — | 区高（毫米） |
| `corner_crop` | object | 否 | — | 四角裁剪（见 3.5a，统一样式） |
| `offset_x_mm` | float | 否 | 0 | 区内 X 微调 |
| `offset_y_mm` | float | 否 | 0 | 区内 Y 微调 |
| `scale` | float | 否 | 1.0 | 缩放系数 |
| `rotation` | float | 否 | 0 | 旋转角度（度） |

#### 3.5a 四角裁剪（corner_crop）

统一裁剪样式，四角一致：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `style` | string | `square` | `square`(方缺角) / `rounded`(圆角) / `chamfer`(三角倒角) |
| `radius_mm` | float | 0 | 圆角半径（`rounded` 时） |
| `chamfer_mm` | float | 0 | 切角边长（`square` 方缺角 / `chamfer` 三角倒角时，四角统一） |

> - `square`：四角各切掉一个 `chamfer_mm × chamfer_mm` 的矩形缺口，形如纸盒展开图缺角。
> - `chamfer`：四角各裁掉等腰直角三角形（斜边），形成八边形轮廓。
> - `rounded`：四角圆角，半径 `radius_mm`。
> - `chamfer_mm = 0` 时 `square`/`chamfer` 不切角（兼容旧配置）。

#### 3.5b 图片区专属字段（type: image）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `fit_mode` | string | `stretch` | `stretch`(拉伸铺满) / `contain`(等比留白) / `cover`(裁切铺满) |

#### 3.5c 纯色区专属字段（type: color）

| 字段 | 类型 | 说明 |
|------|------|------|
| `color` | list | 手动指定 RGB，如 `[255, 200, 100]`。与 `auto_color` 二选一 |
| `auto_color` | object | 自动提取主色。与 `color` 二选一（见 3.5d） |

#### 3.5d 自动主色提取（auto_color）

从指定图片区提取主色填充本纯色区：

| 字段 | 类型 | 说明 |
|------|------|------|
| `source` | string | 来源图片区 `name`，如 `FaceA` |
| `method` | string | `dominant`(主色) / `average`(平均色)，默认 `dominant` |

> 提取在生成时执行：先载入来源图片区对应的上传图，计算主色/平均色，填入纯色区。

### 3.6 标记层（marks）

四类标记，各自独立开关。详见 `04-预检与生成参数` 3.4 标记层。

| 子项 | 字段 | 默认 | 说明 |
|------|------|------|------|
| `crop_marks` | enabled/color/width_mm/dashed/dash_length_mm/gap_length_mm | enabled=true | 裁剪线：沿实际像素包围盒内侧描一圈矩形边 |
| `zipper_marks` | enabled/side/span_mm/pitch_mm/line_width_mm/alignment | enabled=false | 拉链标记线 |
| `text_marks` | enabled/color/font_size_pt/items | enabled=false | 文字标记 |
| `border_marks` | list[{enabled,name,color,x_mm,y_mm,width_mm,height_mm,width_mm_line,dash_length_mm,gap_length_mm}] | `[]` | 虚线边框标记，支持多个，每个一个独立图层 |

#### 3.6b 裁剪线（crop_marks）

沿**主 zone 像素范围**描边，形状跟随主 zone 的 `corner_crop`（square 方缺角画 12 边形 / chamfer 三角倒角画 8 边形 / rounded 画圆角矩形 / 无缺角画矩形）。主 zone 取面积最大的 image zone。background 启用时也沿主 zone 范围描，不画整画布矩形——裁剪线始终标记产品实际轮廓（含缺角）。

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | bool | true | 是否生成 |
| `color` | string | black | 颜色名（black/white/red） |
| `width_mm` | float | 0.2 | 线粗（毫米） |
| `dashed` | bool | false | 是否虚线 |
| `dash_length_mm` | float | 2 | 虚线段长 |
| `gap_length_mm` | float | 2 | 虚线间隙 |

#### 3.6a 拉链标记线（zipper_marks）

标示拉链缝制位置，在某侧均匀排布一组短标记线：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | bool | false | 是否生成 |
| `side` | string | `left` | 所在边：`top` / `bottom` / `left` / `right` |
| `span_mm` | float | — | 首尾间隔：首标记到尾标记的总跨度（毫米） |
| `pitch_mm` | float | — | 相邻标记间距（毫米）；与 `span_mm` 共同决定标记数量 |
| `line_width_mm` | float | 0.5 | 标记线宽 |
| `alignment` | string | `center` | 整组在边上的对齐：`start` / `center` / `end` / `distribute` |
| `offset_mm` | float | 5 | 标记距所选边的偏移 |
| `length_mm` | float | 10 | 每条标记线长度（垂直于边） |
| `color` | string | black | 颜色 |

> 生成逻辑：按 `side` 确定排布方向，`span_mm` 与 `pitch_mm` 计算标记数量（`count = round(span/pitch)+1`），`alignment` 决定整组在边上的起止位置（`distribute` 时均匀铺满整边）。

### 3.7 输出设置（output）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `formats` | list | 是 | 输出格式列表，当前仅 `psd` |

> 印前生成只产出分层 PSD。平面 TIF 由排版阶段产出（见排版配置）。

### 3.9 校验规则

config/prepress.py 加载时必须校验，不合法则启动失败：

- `id` 在同级唯一（类型 id 全局唯一，尺码 id 在类型内唯一），允许中文，仅禁路径非法字符 `/ \ : * ? " < > |` 及空白（id 用于文件名/路径，不写入 PSD；`zone.name` 才写入 PSD，须 ASCII）
- `width_mm` / `height_mm` > 0
- `dpi` ≥ 1
- `bitdepth` ∈ {8, 16}
- `zones` 至少 1 个，`name` 全 ASCII 且尺码内唯一
- 区域 `x/y/width/height_mm` 在画布范围内（`width+2*bleed` × `height+2*bleed`）
- `type` ∈ {image, color}；纯色区 `color` 与 `auto_color` 二选一
- `auto_color.source` 必须指向同尺码内存在的图片区 `name`
- `corner_crop.style` ∈ {square, rounded, chamfer}
- `fit_mode` ∈ {stretch, contain, cover}
- `zipper_marks.side` ∈ {top, bottom, left, right}，`alignment` ∈ {start, center, end, distribute}
- `output.formats` 非空

## 4. 排版配置（impose.json）

### 4.1 设计要点

- 排版输出**不分层**，但**必须保留透明 alpha**（透明区 alpha=0，见 4.3 alpha 语义）
- 输出**普通 TIF**（8bit sRGB + alpha），PSD 尺寸超 30000px 时不产出分层
- 排版输入来源：文件库选图 或 新上传

### 4.2 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `version` | int | 是 | 配置版本号 |
| `presets` | list | 是 | 排版预设列表 |
| 预设 `id` | string | 是 | 预设唯一标识，ASCII |
| 预设 `name` | string | 是 | 显示名，如 `双幅拼版` |
| 预设 `canvas` | object | 是 | 画布幅面（见 4.2a） |
| 预设 `layout` | object | 是 | 拼版方式与网格参数（见 4.2e） |
| 预设 `gutters` | object | 否 | 间距/咬口（见 4.2b） |
| 预设 `marks` | object | 否 | 裁切/标记（见 4.2c） |
| 预设 `output` | object | 是 | 输出设置（见 4.2d） |

#### 4.2a 画布幅面（canvas）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `width_mm` | float | 是 | 画布宽（毫米） |
| `height_mm` | float | 是 | 画布高（毫米） |
| `dpi` | int | 否 | 150，输出分辨率 |
| `bitdepth` | int | 否 | 8，位深 |

#### 4.2b 间距/咬口（gutters）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `horizontal_mm` | float | 否 | 0 | 图件间水平间距 |
| `vertical_mm` | float | 否 | 0 | 图件间垂直间距 |
| `margin_mm` | float | 否 | 0 | 画布边缘留白 |

#### 4.2c 标记（marks）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `crop_marks` | bool | 否 | true | 裁切线 |
| `crop_mark_length_mm` | float | 否 | 5 | 裁切线长度 |
| `crop_mark_offset_mm` | float | 否 | 3 | 裁切线距图件偏移 |
| `registration_marks` | bool | 否 | false | 套准标记 |

#### 4.2d 输出设置（output）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `format` | string | 是 | `tif`（普通 TIF，不分层带 alpha） |
| `compression` | string | 否 | `deflate` |
| `color_profile` | string | 否 | `srgb` |

#### 4.2e 拼版方式（layout）

本期仅支持网格拼版（`grid`）。详见 `05b-排版规范` §3。

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `mode` | string | 是 | — | 拼版方式，本期仅 `grid` |
| `rows` | int | 是 | — | 网格行数（≥1） |
| `cols` | int | 是 | — | 网格列数（≥1） |
| `default_fit_mode` | string | 否 | `stretch` | 槽位默认适配方式 ∈ {stretch, contain, cover} |

> 槽位图件映射、`rotation`、`fit_mode` 覆盖在任务提交时指定（见 `05b` §4.2、§5）。

### 4.3 alpha 语义（定稿）

排版输出的 TIF **必须带 alpha 通道**，透明像素含义：

- **alpha = 0（透明）**：**裁切掉的区域**——画布上被裁切线界定、不保留成品的区域（画布留白、间距、裁切外区域）。交付时透明，后道按裁切线去除。
- **alpha = 255（不透明）**：保留成品的区域，承载实际图案。

即：透明区 = 要被裁切掉的部分。

### 4.4 示例

```json
version: 1
presets:
  - id: double_bedsheet
    name: 双幅床单拼版
    canvas:
      width_mm: 2600
      height_mm: 9000
      dpi: 150
      bitdepth: 8
    layout:
      mode: grid
      rows: 1
      cols: 2
      default_fit_mode: stretch
    gutters:
      horizontal_mm: 10
      vertical_mm: 10
      margin_mm: 20
    marks:
      crop_marks: true
      crop_mark_length_mm: 5
      crop_mark_offset_mm: 3
      registration_marks: false
    output:
      format: tif
      compression: deflate
      color_profile: srgb

  - id: quilt_ab_combo
    name: 被罩AB面拼版
    canvas:
      width_mm: 2100
      height_mm: 4800
      dpi: 150
    layout:
      mode: grid
      rows: 1
      cols: 2
    gutters:
      horizontal_mm: 5
      vertical_mm: 5
    marks:
      crop_marks: true
    output:
      format: tif
      compression: deflate
```

### 4.5 校验规则

- `id` 全局唯一，ASCII
- `canvas.width_mm` / `height_mm` > 0
- `layout.mode` ∈ {`grid`}（本期仅一种）
- `layout.rows` / `layout.cols` ≥ 1，整数
- `layout.default_fit_mode` ∈ {`stretch`, `contain`, `cover`}
- 提交时 `slots` 长度 = `rows * cols`，可含 `null`（空槽位）
- 槽位 `rotation` ∈ {0, 90, 180, 270}
- 大尺寸预警：画布像素超 30000×30000 时日志提示"将输出平面 TIF，无分层"
- 超过普通 TIF 4GB 上限（16bit 大画布）时报错，提示改 bigtiff

## 5. 配置加载与热更新

- 启动时加载两个配置文件，校验失败则进程拒绝启动
- **热更新**（待定）：是否监听文件变更自动重载，还是重启生效？见 `03-整体架构` 开放问题
- config 模块对外提供查询 API：
  - `list_types()` → 类型列表
  - `get_sizes(type_id)` → 该类型尺码列表
  - `get_params(type_id, size_id)` → 印前参数
  - `list_impose_presets()` → 排版预设
  - `get_impose_preset(preset_id)` → 排版参数
  - `get_storage()` → 存储配置（含 `tasks.max_concurrency`）
- 存储配置写入 API（任务并发上限可在线改，校验后落盘并 `reload_all()` 立即生效）：
  - `update_tasks_concurrency(max_concurrency)` → 改 `tasks.max_concurrency`（≥1），落盘 + 重载，调度器动态读取，新任务按新上限排队执行
- 印前配置写入 API（配置管理页用，校验后落盘并 `reload_all()` 立即生效）：
  - `save_size_config(type_id, size_id, data)` → 保存尺码（`data` 含 type/size/name/params，**type/size 须与路径一致**，可改 `name` 与 `params`）
  - `create_size_config(type_id, size_id, name, params)` → 新建尺码（允许新建类型）
  - `delete_size_config(type_id, size_id)` → 删除尺码（不允许删空类型）
  - `rename_size_config(old_type, old_size, new_type, new_size, new_name)` → 重命名尺码的 type/size id 与显示名：重命名文件、改写文件内 type/size/name 字段、校验新 id 唯一性与合法性后 `reload_all()`
