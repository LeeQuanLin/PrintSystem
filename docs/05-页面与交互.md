# 05 - 页面与交互

> 状态：规划中 · 最后更新：2026-08-26
> 聚焦：印前生成页面交互。排版拼版规则见 `05b-排版规范`；排版页面交互待补本文档。

## 1. 印前生成页面工作流

### 1.1 主流程

```
① 选择印前类型  →  ② 选择尺码  →  ③ 页面动态展示图片上传区  →  ④ 上传图 + 微调  →  ⑤ 生成
```

操作员进入印前处理页面后：

1. **选择类型**：从配置树第一级选（床单/被罩AB面/枕套…）
2. **选择尺码**：类型选定后，下拉出现该类型尺码列表，选其一
3. **页面动态更新**：根据所选尺码的 `zones` 配置，**实时**在页面上渲染对应数量的图片上传区
4. **上传与微调**：在上传区放入图片，可网页微调 offset/scale/rotation
5. **生成**：触发后服务端按配置 + 微调参数生成分层 PSD，入文件库

### 1.2 动态上传区（核心交互）

页面根据尺码配置的 `zones` 中**图片区**（`type: image`）数量，实时渲染上传区：

- 单图片区（如床单）→ 页面显示 **1 个上传区**
- 多图片区（如被罩AB面 FaceA/FaceB）→ 页面显示 **多个上传区**

> 纯色区（`type: color`）不产生上传区，生成时按配置填充。

每个图片区支持**两种取图方式**：

| 方式 | 行为 |
|------|------|
| 上传 | 点击/拖入本地图片，走 `/api/upload` 入库后取库内路径 |
| 从文件库选择 | 弹出文件库网格（缩略图 + 搜索），选中已有图，直接取库内原图路径 |

两种方式最终都产出库内原图路径，填入生成参数 `image_path`，生成流程无差异。选中后上传区显示该图缩略图预览与文件名，可点击更换。

### 1.3 同图/多图复选框

多图片区场景下，页面提供**复选框**："是否使用同一张图"：

| 选项 | 行为 |
|------|------|
| ☑ 同一张图 | 页面合并为 **1 个上传区**，上传的图应用到所有图片区 |
| ☐ 多张图 | 每个图片区一个独立上传区，分别上传，分别对应 |

复选框切换时，页面**实时更新**上传区数量与布局。

### 1.4 页面流转示意

```
┌──────────────────────────────────────────────────────────┐
│  类型: [床单 ▼]   尺码: [150x200 ▼]                       │
├──────────────────────────────────────────────────────────┤
│  ☑ 多图时是否同一张图（单图区时隐藏此项）                  │
├──────────────────────────────────────────────────────────┤
│   ┌──────────┐   ┌──────────┐    ← 上传区随配置动态出现   │
│   │ FaceA    │   │ FaceB    │                              │
│   │ [上传]   │   │ [上传]   │                              │
│   │ 微调…    │   │ 微调…    │                              │
│   └──────────┘   └──────────┘                              │
├──────────────────────────────────────────────────────────┤
│                                  [ 生成印前文件 ]         │
└──────────────────────────────────────────────────────────┘
```

## 2. 微调交互

每个图片区支持网页微调，覆盖配置默认值：

| 微调项 | 对应配置字段 | 交互 |
|--------|------------|------|
| 位置平移 | `offset_x_mm` / `offset_y_mm` | 拖拽图片在区内移动 |
| 缩放 | `scale` | 滑块或滚轮 |
| 旋转 | `rotation` | 滑块或角度输入 |

> 微调值随生成请求提交，覆盖配置默认值。纯色区不支持微调。

### 2.1 多图独立配置（定稿）

**同图模式下，各图片区的 fit_mode / corner_crop / 微调依然各自独立**。即"同一张图"只指图源相同，各区的裁剪、适配、微调仍按各自配置执行。

## 3. 实时预览

微调时**实时预览**，不用等提交：

- 页面合成**定比缩略图**（按画布宽高比缩放，固定预览尺寸），操作员所见即所得
- 预览在前端/轻量后端完成，仅用于可视化，非最终输出
- 操作员确认后再提交到队列，后台生成最终分层 PSD

```
微调操作 → 实时合成定比缩略图 → 操作员确认 → 入队列 → 后台生成
```

> 预览缩略图与文件库缩略图规格统一（见 `07-文件存储`）。

## 4. 页面与配置的对应

| 页面元素 | 配置来源 |
|---------|---------|
| 类型下拉 | `prepress.json` types[].id/name |
| 尺码下拉 | types[].sizes[].id/name |
| 上传区数量 | params.zones[type=image] 的数量 |
| 上传区名称 | zone.name |
| 微调范围 | zone 的 offset/scale/rotation 字段 |

## 5. 生成请求

生成时页面提交：

```json
{
  "type_id": "quilt_ab",
  "size_id": "200x230",
  "images": {
    "FaceA": "<file>",
    "FaceB": "<file>"
  },
  "overrides": {
    "FaceA": {"offset_x_mm": 2, "scale": 1.05},
    "FaceB": {"offset_y_mm": -1}
  }
}
```

- `images`：区名 → 上传文件映射。同图模式时所有图片区指向同一文件
- `overrides`：区名 → 微调参数，覆盖配置默认值（可选）

## 6. 配置图形化编辑器

印前配置页（`/config/prepress`）除原有 JSON 文本编辑外，提供图形化编辑器，降低手写 JSON 门槛。两者 **tab 切换、双向同步**，共享同一份 `params`。

### 6.1 三栏布局

选中某尺码后，编辑区呈现三栏：

| 栏 | 内容 |
|----|------|
| 左栏 · 模块导航 | 画布 / 背景 / 区域（zones 列表）/ 裁剪线 / 拉链标记 / 文字标记 / 边框标记 / 输出。点击切换右栏表单 |
| 中栏 · 画布预览 | SVG 按 mm 比例渲染：出血虚线框、成品实线框、zones 矩形（image 区与 color 区区分色）、选中高亮、边框标记预览 |
| 右栏 · 参数表单 | 随左栏选中模块动态切换：数值输入、下拉、颜色选择器、开关等控件 |

### 6.2 画布预览范围

- zones 位置/尺寸实时反映在画布（改右栏数值，画布即时更新）
- 点击画布 zone 矩形 → 选中该 zone，右栏切到其表单
- 边框标记（矩形虚线）在画布叠加预览
- 裁剪线 / 拉链标记 / 文字标记：本期**仅表单可配**，不在画布渲染（分布算法复杂，留后续）

### 6.3 JSON 与图形双向同步

- 切到 JSON tab：`JSON.stringify(params)`，可手动编辑
- 切回图形 tab：`JSON.parse` 回内存并重渲染（语法错误则提示且不切换）
- 保存时整体 `PUT`，后端 Pydantic 校验兜底，错误回显

> 区域 name 限 ASCII、zones 须在画布范围内等校验由后端 `Params` 模型统一兜底（见 `02-配置文件规范` §3.9）。

## 9. 排版拼版页面（已实现 · 原尺寸流式铺排）

页面路由 `/impose`，模板 `impose.html`，逻辑 `impose.js`。
**自由配置工作流**：无预设，左侧添加图件并排序/旋转，中间实时预览，右侧填画布参数，提交入队列。
图件按原始尺寸（仅旋转，不缩放）行优先流式铺排，从画布左上角开始，无间距无边距。

### 9.1 主流程

```
左侧添加图件（上传/文件库多选）→ 调顺序与旋转 → 右侧填画布宽高/DPI/保存名 → 中间实时预览 → 提交 → WS 进度 → 下载 TIF
```

### 9.2 左侧：图件列表

- "上传图片"（多选）/ "从文件库选"（picker 多选，勾选+确认批量加入）
- 图件按列表顺序即铺排顺序
- 每项：缩略图 + 名称 + 旋转下拉（0/90/180/270）+ ↑/↓ 移序 + × 删除
- 图件不缩放，只旋转，按原始尺寸摆放

### 9.3 中间：预览画布

- 前端 Canvas 实时按比例绘制：图件缩略图（原尺寸按画布比例缩放）+ 透明区棋盘格
- 配置或图件变动即时重绘

### 9.4 右侧：内联配置

- 画布宽/高（mm）、DPI、保存格式（tif）、保存名
- 无预设、无列数、无间距边距、无 fit_mode

### 9.5 提交

- `POST /api/impose/submit`，body：`{canvas:{width_mm,height_mm,dpi}, output?, save_name?, slots:[{image_id, rotation}]}`
- 后端校验：canvas 宽高>0、dpi≥1、slots 非空、rotation ∈ {0,90,180,270}
- 后端构造 `Preset`（layout/gutters 占位，引擎用流式布局）传给 `impose.run()`
- **超出报错**：任一图件（含旋转后）超出画布边界则任务失败
- image_id → 文件路径在 web 层解析，引擎只收路径（解耦存储）

### 9.6 任务进度与下载

- 复用全站 WS 任务队列（`taskStore`），排版任务与印前任务同表展示
- 进度阶段：载入图件 0-30 / 拼版合成 30-80 / 写 TIF 85-100
- 完成后下载 TIF + 缩略图；产物入库 source=impose

### 9.7 预设基础设施保留

`impose.json` 预设与 `/api/config/impose` 只读配置页保留（供查阅），工作流页不再使用预设。`Preset` 模型被复用为内联配置容器。
