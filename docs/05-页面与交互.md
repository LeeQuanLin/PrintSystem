# 05 - 页面与交互

> 状态：规划中 · 最后更新：2026-08-26
> 聚焦：印前生成页面交互。排版拼版规则见 `05b-排版规范`；排版页面交互待补本文档。

## 1. 印前生成页面工作流

### 1.1 主流程

```
① 选择印前类型  →  ② 选择尺码  →  ③ 页面动态展示图片上传区  →  ④ 上传图 + 微调  →  ⑤ 生成
```

操作员进入印前处理页面后：

1. **选择类型**：从配置树第一级选（床单/被罩AB面/枕套…）
2. **选择尺码**：类型选定后，下拉出现该类型尺码列表，选其一
3. **页面动态更新**：根据所选尺码的 `zones` 配置，**实时**在页面上渲染对应数量的图片上传区
4. **上传与微调**：在上传区放入图片，可网页微调 offset/scale/rotation
5. **生成**：触发后服务端按配置 + 微调参数生成分层 PSD，入文件库

### 1.2 动态上传区（核心交互）

页面根据尺码配置的 `zones` 中**图片区**（`type: image`）数量，实时渲染上传区：

- 单图片区（如床单）→ 页面显示 **1 个上传区**
- 多图片区（如被罩AB面 FaceA/FaceB）→ 页面显示 **多个上传区**

> 纯色区（`type: color`）不产生上传区，生成时按配置填充。

### 1.3 同图/多图复选框

多图片区场景下，页面提供**复选框**："是否使用同一张图"：

| 选项 | 行为 |
|------|------|
| ☑ 同一张图 | 页面合并为 **1 个上传区**，上传的图应用到所有图片区 |
| ☐ 多张图 | 每个图片区一个独立上传区，分别上传，分别对应 |

复选框切换时，页面**实时更新**上传区数量与布局。

### 1.4 页面流转示意

```
┌──────────────────────────────────────────────────────────┐
│  类型: [床单 ▼]   尺码: [150x200 ▼]                       │
├──────────────────────────────────────────────────────────┤
│  ☑ 多图时是否同一张图（单图区时隐藏此项）                  │
├──────────────────────────────────────────────────────────┤
│   ┌──────────┐   ┌──────────┐    ← 上传区随配置动态出现   │
│   │ FaceA    │   │ FaceB    │                              │
│   │ [上传]   │   │ [上传]   │                              │
│   │ 微调…    │   │ 微调…    │                              │
│   └──────────┘   └──────────┘                              │
├──────────────────────────────────────────────────────────┤
│                                  [ 生成印前文件 ]         │
└──────────────────────────────────────────────────────────┘
```

## 2. 微调交互

每个图片区支持网页微调，覆盖配置默认值：

| 微调项 | 对应配置字段 | 交互 |
|--------|------------|------|
| 位置平移 | `offset_x_mm` / `offset_y_mm` | 拖拽图片在区内移动 |
| 缩放 | `scale` | 滑块或滚轮 |
| 旋转 | `rotation` | 滑块或角度输入 |

> 微调值随生成请求提交，覆盖配置默认值。纯色区不支持微调。

### 2.1 多图独立配置（定稿）

**同图模式下，各图片区的 fit_mode / corner_crop / 微调依然各自独立**。即"同一张图"只指图源相同，各区的裁剪、适配、微调仍按各自配置执行。

## 3. 实时预览

微调时**实时预览**，不用等提交：

- 页面合成**定比缩略图**（按画布宽高比缩放，固定预览尺寸），操作员所见即所得
- 预览在前端/轻量后端完成，仅用于可视化，非最终输出
- 操作员确认后再提交到队列，后台生成最终分层 PSD

```
微调操作 → 实时合成定比缩略图 → 操作员确认 → 入队列 → 后台生成
```

> 预览缩略图与文件库缩略图规格统一（见 `07-文件存储`）。

## 4. 页面与配置的对应

| 页面元素 | 配置来源 |
|---------|---------|
| 类型下拉 | `prepress.json` types[].id/name |
| 尺码下拉 | types[].sizes[].id/name |
| 上传区数量 | params.zones[type=image] 的数量 |
| 上传区名称 | zone.name |
| 微调范围 | zone 的 offset/scale/rotation 字段 |

## 5. 生成请求

生成时页面提交：

```json
{
  "type_id": "quilt_ab",
  "size_id": "200x230",
  "images": {
    "FaceA": "<file>",
    "FaceB": "<file>"
  },
  "overrides": {
    "FaceA": {"offset_x_mm": 2, "scale": 1.05},
    "FaceB": {"offset_y_mm": -1}
  }
}
```

- `images`：区名 → 上传文件映射。同图模式时所有图片区指向同一文件
- `overrides`：区名 → 微调参数，覆盖配置默认值（可选）

## 6. 开放问题

1. **微调粒度**：拖拽的最小步长（mm）？是否吸附网格？
2. **预览实现位置**：前端 Canvas 合成 vs 轻量后端接口？大图时前端可能吃力
3. **纯色区展示**：纯色区在页面上是否可见预览（显示提取/手动色）？
