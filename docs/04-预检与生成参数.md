# 04 - 预检与生成参数

> 状态：规划中 · 最后更新：2026-08-26
> 聚焦：印前文件生成。排版部分见 `05b-排版规范`。

## 1. 概述

印前生成的职责：读取上传图 + 尺码配置（`prepress.json`），经过**预检 → 生成**两个阶段，产出**分层 PSD**，入文件库。

```
上传图 ──▶ 预检 ──▶ 生成（裁放/出血/分层） ──▶ 分层 PSD ──▶ 文件库
         (格式/尺寸/   (按 params)             (psd-tools)
          分辨率检查)
```

本文档定义预检规则与生成各层的具体参数与逻辑。

## 2. 预检（Preflight）

### 2.1 预检目标

校验上传图是否满足所选尺码的生成要求，不达标给出提示，避免生成废品。

### 2.2 预检项

| 检查项 | 规则 | 不达标处理（待定策略） |
|--------|------|----------------------|
| **格式** | 支持 PNG / JPG / TIFF / PSD（具体范围见 `01-需求` 开放问题 2） | 阻断，拒绝生成 |
| **尺寸** | 上传图像素 ≥ 成品 + 出血所需像素（见 2.3） | 警告，可选强制生成或阻断 |
| **分辨率** | 上传图 DPI ≥ 配置 `dpi`（按物理尺寸换算） | 警告，不足时放大补足 |
| **色彩模式** | RGB / CMYK / 灰度等，转换到配置 `color_profile` | 警告并自动转换 |
| **位深** | 上传图位深与配置 `bitdepth` 比较 | 自动转换（高→低警告） |
| **通道** | 是否含 alpha | 记录，生成时按需处理 |

### 2.3 尺寸换算

成品 + 出血所需像素：

```
所需宽 px = (width_mm + 2 * bleed_mm) * dpi / 25.4
所需高 px = (height_mm + 2 * bleed_mm) * dpi / 25.4
```

上传图像素 < 所需 → 尺寸不足。

### 2.4 预检结果

预检返回结构化报告：

```python
{
  "passed": bool,           # 是否通过
  "warnings": [str],        # 警告项（可继续）
  "errors": [str],          # 阻断项（不可继续）
  "input_info": {           # 上传图实际信息
      "format": "png",
      "width_px": 2400,
      "height_px": 3200,
      "dpi": 72,
      "mode": "RGB",
      "bitdepth": 8
  },
  "required": {             # 配置要求
      "width_px": 1536,
      "height_px": 2041,
      "dpi": 150
  }
}
```

### 2.5 不达标处理策略（待定）

见 `01-需求与目标` 开放问题 4。候选：
- A：阻断——必须换合格原图
- B：警告——允许继续，后果自负
- C：自动修正——放大/转色彩，但可能损质量

> 倾向：格式错阻断，尺寸/分辨率不足警告 + 自动放大，色彩/位深自动转换。

## 3. 生成（Generate）

### 3.1 生成目标

按尺码 `params` 处理上传图，组装分层 PSD。**所有输出为分层 PSD**（不分层 TIF 由排版阶段产出）。

### 3.2 生成流程

```
1. 计算画布像素 = (width_mm + 2*bleed) × (height_mm + 2*bleed) @ dpi
2. 生成背景层（若 enabled）
3. 处理图片区（type=image）：上传图 → fit_mode 适配 → 四角裁剪 → 微调
4. 处理纯色区（type=color）：
   a. 手动色：直接填充 color
   b. 自动色：载入 auto_color.source 指向的图片区上传图，提取主色/平均色填充
5. 生成标记层：裁剪线 + 拉链标记线 + 文字标记（按 enabled）
6. 组装分层 PSD（psd-tools），层名用区名/标记名（ASCII）
7. 写入 data/library/images（文件库，见 07-文件存储），同时生成缩略图
```

### 3.3 画布与图片放置区

- **画布**：`(width_mm + 2*bleed_mm) × (height_mm + 2*bleed_mm)`，出血环绕四周
- **图片放置区**：画布上可配置 1 个或多个矩形区，每个区独立尺寸/位置/裁剪/微调，承载上传图
- 区之间可相邻（如被罩 A/B 面并排）或分散（如立方体展开多面）
- 标记层（裁剪线/拉链/文字）叠在图片区之上

```
画布（含出血）
┌───────────────────────────────┐
│  出血                          │
│  ┌──────────┐  ┌──────────┐   │
│  │ 图片区A   │  │ 图片区B   │   │ ← 可多个区，独立配置
│  │ (上传图)  │  │ (上传图)  │   │
│  └──────────┘  └──────────┘   │
│  裁剪线/拉链/文字标记叠在其上   │
│  出血                          │
└───────────────────────────────┘
```

> 单图片区时即退化为单一图案层；多图片区时各承载不同面/不同图。

### 3.4 各层生成参数

#### 背景层（background）

| 参数 | 说明 |
|------|------|
| 填充色 | 默认白色 `(255,255,255)`，可配置 |
| 范围 | 整个画布（含出血） |
| 位置 | 最底层 |

> 是否需要背景层由 `layers` 配置决定；无背景层时画布透明。

#### 区域（zones，核心机制）

一个尺码的 PSD 可包含**多个区域**（如被罩 A/B 面、立方体展开多面）。每个区独立配置尺寸/位置/裁剪/微调。区有两类：
- **图片区**（`type: image`）：承载上传图，按 `fit_mode=stretch`（默认拉伸）铺满
- **纯色区**（`type: color`）：填充纯色，可手动指定或从某图片区自动提取主色

**区域基础字段**（两类共享）：

| 字段 | 类型 | 必填 | 默认 | 说明 |
|------|------|------|------|------|
| `name` | string | 是 | — | 区名，ASCII，如 `FaceA` / `Border` |
| `type` | string | 是 | `image` | `image` / `color` |
| `x_mm` | float | 是 | — | 区左上角 X（毫米，相对画布左上角） |
| `y_mm` | float | 是 | — | 区左上角 Y（毫米） |
| `width_mm` | float | 是 | — | 区宽（毫米） |
| `height_mm` | float | 是 | — | 区高（毫米） |
| `corner_crop` | object | 否 | — | 四角裁剪（见下） |
| `offset_x_mm` | float | 否 | 0 | 区内 X 微调（毫米） |
| `offset_y_mm` | float | 否 | 0 | 区内 Y 微调（毫米） |
| `scale` | float | 否 | 1.0 | 缩放系数（1.0 = 原始适配） |
| `rotation` | float | 否 | 0 | 旋转角度（度，顺时针） |

**四角裁剪（corner_crop，统一样式）**：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `style` | string | `square` | 裁剪样式：`square`(直角) / `rounded`(圆角) / `chamfer`(切角) |
| `radius_mm` | float | 0 | 圆角半径（`rounded` 时） |
| `chamfer_mm` | float | 0 | 切角边长（`chamfer` 时，四角统一） |

> `square` 即不裁剪，保持直角；`chamfer` 四角各裁掉一个等腰直角三角形，形成八边形轮廓。

**图片区专属**：`fit_mode` ∈ {stretch, contain, cover}，默认 `stretch`。

**纯色区专属**：`color`（手动 RGB）或 `auto_color`（从 `source` 图片区提取主色/平均色）。提取在生成时执行。

**区域列表**：`params.zones`。PSD 中每个区为一个图层（或图层组），层名用区名。

#### 标记层（mark，多类标记）

标记层包含三类标记，可单独开关：

##### 裁剪线（crop_marks）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | bool | true | 是否生成 |
| `color` | string | black | 线颜色 |
| `width_mm` | float | 0.2 | 线宽 |
| `length_mm` | float | 5 | 裁切线长度 |
| `offset_mm` | float | 3 | 距成品边偏移 |

##### 拉链标记线（zipper_marks）

标示拉链缝制位置，在某侧均匀排布一组短标记线：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | bool | false | 是否生成 |
| `side` | string | `left` | 所在边：`top` / `bottom` / `left` / `right` |
| `span_mm` | float | — | 首尾间隔：首标记到尾标记的总跨度（毫米） |
| `pitch_mm` | float | — | 相邻标记间距（毫米）；与 `span_mm` 共同决定标记数量 |
| `line_width_mm` | float | 0.5 | 标记线宽 |
| `alignment` | string | `center` | 整组在边上的对齐：`start` / `center` / `end` / `distribute` |
| `offset_mm` | float | 5 | 标记距所选边的偏移 |
| `length_mm` | float | 10 | 每条标记线长度（垂直于边） |
| `color` | string | black | 颜色 |

> 生成逻辑：按 `side` 确定排布方向，`span_mm` 与 `pitch_mm` 计算标记数量（`count = round(span/pitch)+1`），`alignment` 决定整组在边上的起止位置（`distribute` 时均匀铺满整边）。

##### 文字标记（text_marks）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `enabled` | bool | false | 是否生成 |
| `color` | string | black | 文字颜色 |
| `font_size_pt` | float | 12 | 字号 |
| `items` | list | [] | 文字项列表（见下） |

文字项（items 每项）：

| 字段 | 类型 | 说明 |
|------|------|------|
| `text` | string | 文字内容，如尺码、品名、面别（如 `A面` / `150x200`） |
| `x_mm` | float | 位置 X（毫米） |
| `y_mm` | float | 位置 Y（毫米） |
| `rotation` | float | 旋转角度 |

### 3.5 配置字段最终结构

综合上述，`prepress.json` 的 `params` 完整结构（回写 `02-配置文件规范`）：

```json
params:
  width_mm: 1500
  height_mm: 2000
  bleed_mm: 3
  dpi: 150
  bitdepth: 8
  color_profile: srgb
  background:
    enabled: true
    fill_color: [255, 255, 255]
  zones:
    - name: FaceA
      x_mm: 3
      y_mm: 3
      width_mm: 1494
      height_mm: 1994
      fit_mode: stretch
      corner_crop:
        style: square
      offset_x_mm: 0
      offset_y_mm: 0
      scale: 1.0
    - name: FaceB
      x_mm: 1500
      y_mm: 3
      width_mm: 1494
      height_mm: 1994
      fit_mode: stretch
      corner_crop:
        style: chamfer
        chamfer_mm: 20
  marks:
    crop_marks:
      enabled: true
      color: black
      width_mm: 0.2
      length_mm: 5
      offset_mm: 3
    zipper_marks:
      enabled: true
      positions:
        - side: top
          offset_mm: 50
    text_marks:
      enabled: true
      items:
        - text: "A 150x200"
          x_mm: 10
          y_mm: 10
  output:
    formats: [psd]
```

## 4. 输出

### 4.1 输出格式

- **仅 PSD**（分层），由 psd-tools 写入
- 图层名 ASCII（如 `Background` / `Pattern` / `Mark`）
- DPI 写入 PSD 元数据（`xres` / `yres`）

### 4.2 写入文件库

- 输出到 `data/library/images/{id}/`（见 `07-文件存储`）
- 命名规则见 `07-文件存储`（待定）
- 同时生成缩略图（Pillow），供网页展示
- 大尺寸（超 30000px）时不产出 PSD，降级处理（见开放问题）

## 5. 预检与生成的配置关联

| 生成参数 | 配置来源 | 字段 |
|----------|----------|------|
| 画布尺寸 | prepress.json | `params.width_mm/height_mm/bleed_mm` |
| 分辨率 | prepress.json | `params.dpi` |
| 位深 | prepress.json | `params.bitdepth` |
| 色彩 | prepress.json | `params.color_profile` |
| 分层 | prepress.json | `params.layers` |
| 图案适配 | prepress.json | `layers[Pattern].fit_mode`（建议） |
| 标记 | prepress.json | `layers[Mark].crop_marks` 等（建议） |

## 6. 开放问题

1. **不达标处理策略**：阻断 / 警告 / 自动修正（见 2.5）
2. **大尺寸 PSD 降级**：单产品超 30000px 时如何处理？降级平面 TIF 还是拒绝？
3. **背景层默认**：无背景层时画布透明，还是强制白底？
4. **多区上传图映射**（已定）：多图片区由页面复选框决定同图/多图；同图模式下各图片区 fit_mode/裁剪/微调仍各自独立，详见 `05-页面与交互`
5. **文字标记字体**：默认字体、中文字符是否需要（PSD 文字层 ASCII 限制）？
6. **网页微调数据回传**：操作员网页微调的 offset/scale/rotation 如何随生成请求提交，覆盖配置默认值？
7. **主色提取算法**：dominant 用何种算法（K-means / 直方图众数 / 色彩量化），待实现时定
